PITLAUNCH 1.0
=============

Welcome to PitLaunch.

FIRST RUN
1. Start PitLaunch and choose Start guided setup.
2. Name the place, select and arrange its displays, choose sound, then review it.
3. Repeat once at the other place so PitLaunch has both a Desk and Sim Racing setup.
4. Use Switch, the tray, a hotkey, game detection, or Stream Deck to move between them.

WINDOWS SMARTSCREEN
PitLaunch 1.0 is not code-signed yet. Windows may show a warning the first time.
Download only from the official GitHub release, verify SHA256SUMS.txt, then choose
More info > Run anyway.

SAFETY
- Manual setup switches ask for confirmation when Confirm before switching is enabled.
- Automatic game, hotkey, command-line, and Stream Deck switches do not show a prompt.
- Ctrl+Alt+Shift+F12 enables every display Windows currently detects.
- Undo restores the hardware state from before the last switch.

SUPPORT
Use Settings > Support > Export support bundle. It creates a privacy-sanitized ZIP.
Bug reports: https://github.com/Cevzom/PitLaunch/issues/new/choose

The complete Hebrew and English guide is here:
https://github.com/Cevzom/PitLaunch/blob/main/docs/USER-GUIDE.md

Setups are stored in %APPDATA%\PitLaunch and are not removed by updates.
