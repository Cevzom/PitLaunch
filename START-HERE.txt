PITLAUNCH BETA 0.9.1 - עברית
===========================

תודה שאתם בודקים את PitLaunch.

התקנה
1. חלצו את כל תוכן ה-ZIP לתיקייה קבועה.
2. הפעילו את PitLaunch.exe באופן רגיל. אין צורך בהרשאות מנהל מערכת.
3. Windows SmartScreen עשוי להציג אזהרה מכיוון שגרסת הבטא עדיין אינה חתומה דיגיטלית.
4. צרו מצב Desk ומצב Sim racing מהציוד ש-PitLaunch מזהה.

הפעלה עם WINDOWS
- Start with Windows מוסיף שתי דרכי הפעלה רגילות ואינו דורש הרשאות מנהל.
- אם Windows עדיין מדלג על ההפעלה, לחצו על כפתור המגן Reliable startup.
- אפשרות הגיבוי מבקשת אישור מנהל פעם אחת בלבד; PitLaunch עצמה ממשיכה לפעול בהרשאות רגילות.

בטיחות
- PitLaunch מבקשת אישור לפני החלפת מצב כברירת מחדל.
- Restore displays מפעיל את כל המסכים ש-Windows מזהה כרגע.
- קיצור חירום: Ctrl+Alt+Shift+F12
- הקיצור פועל כאשר PitLaunch פתוחה, גם כשהיא מוסתרת באזור ההתראות.
- ניתן גם להריץ: PitLaunch.exe --restore-displays
- מסכים והתקני שמע שאינם זמינים יידלגו במקום לגרום לקריסה.

דיווח על תקלה
שלחו תיאור של השלבים שגרמו לתקלה ואת הקובץ:
%APPDATA%\PitLaunch\pitlaunch.log

הפרופילים וההגדרות נשמרים כאן:
%APPDATA%\PitLaunch\profiles.json

כפתור הסגירה מעביר את PitLaunch לאזור ההתראות. לפני החלפה או מחיקה של
PitLaunch.exe, לחצו לחיצה ימנית על סמל PitLaunch ובחרו Exit.


PITLAUNCH BETA 0.9.1 - ENGLISH
==============================

Thank you for testing PitLaunch.

INSTALL
1. Extract this entire ZIP to a permanent folder.
2. Run PitLaunch.exe normally. Administrator access is not required.
3. Windows SmartScreen may warn because this beta is not code-signed.
4. Create a Desk setup and a Sim racing setup from the devices PitLaunch finds.

WINDOWS STARTUP
- Start with Windows adds two normal startup paths and needs no administrator access.
- If Windows still skips startup, click the shield-marked Reliable startup button.
- The fallback asks for approval once; PitLaunch itself continues at normal permission level.

SAFETY
- PitLaunch asks for confirmation before changing setups by default.
- Restore displays enables every monitor Windows currently detects.
- Emergency shortcut: Ctrl+Alt+Shift+F12
- The shortcut works while PitLaunch is running, including from the tray.
- You can also run: PitLaunch.exe --restore-displays
- Missing monitors and audio devices are skipped instead of crashing.

BUG REPORTS
Send the steps that caused the problem and this file:
%APPDATA%\PitLaunch\pitlaunch.log

The app stores profiles and settings here:
%APPDATA%\PitLaunch\profiles.json

The close button sends PitLaunch to the tray. Right-click the tray icon and
choose Exit before replacing or deleting PitLaunch.exe.
