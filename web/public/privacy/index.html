Privacy

Privacy Policy

The short version: PitLaunch runs on your PC and stays on your PC. Nothing below changes that — it just says so precisely.

The short version

PitLaunch does not collect, transmit, or store any personal data on any server. Every setup you create — displays, audio, window positions, applications — is saved in a file on your own PC. There is no account, no sign-in, and no tracking of any kind.

What's stored, and where

Your setups live locally, in %APPDATA%\PitLaunch, on the PC PitLaunch is installed on. That includes:

  • Display layouts — which monitors, resolution, refresh rate, and arrangement
  • Audio device preferences
  • Window positions
  • Configured application lists

None of it leaves your machine. PitLaunch has no server to send it to.

No telemetry, no analytics, no tracking

PitLaunch does not phone home to report how you use it. No usage analytics, no crash reporting to a third party, no tracking identifiers. What you do with the app is not PitLaunch's business.

No account required

There is nothing to sign in to. Downloading and running PitLaunch is the entire setup process.

The only network activity

PitLaunch's installed copy checks GitHub in the background for a newer release. That request includes the app version and your OS — enough to know whether an update applies — and nothing tied to you personally. If you choose to update, it downloads the changed files from GitHub. That's the entire list of things PitLaunch does over a network.

If Pro licensing is added later

PitLaunch 1.0 has no paid tier. If a Pro license is introduced in a future version, activating it will validate the license key against Lemon Squeezy's servers, since Lemon Squeezy is the payment processor handling the purchase. Your license email is stored by Lemon Squeezy, not by PitLaunch — the app never has a server of its own to store it on. This policy will be updated if and when that ships.

This website

pitlaunch.net does not use cookies, analytics, or tracking of any kind. The only third-party request the site makes is to Google Fonts, to load the typefaces used in the page design.

Contact

Questions about this policy, or anything else, belong on GitHub Issues.

Changes

Effective date: August 15, 2026.

This policy may be updated as PitLaunch gains features, particularly if a Pro tier ships. The GitHub repository and its changelog are the source of truth for what the app actually does at any given time.
