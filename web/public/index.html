Trust is a feature

A display switch should never leave you blind.

PitLaunch treats each switch as a transaction, with a way back even when hardware has changed.

01

Preflight

Windows checks whether the saved display layout is valid before PitLaunch applies it.

02

Rollback

If a step fails partway through, PitLaunch restores the previous state instead of leaving a half-switch.

03

Rescue

Ctrl + Alt + Shift + F12 turns every detected display back on.

Before you install

Frequently asked questions.

Pick a topic. The useful answer is probably short.

Is PitLaunch free?

Yes. PitLaunch 1.0 is free to use. Its source is publicly viewable, but PitLaunch is proprietary software and all rights are reserved.

Does it need an account or internet connection?

No account. Your setups stay on your PC. Internet is only used to check GitHub for updates.

Will Windows SmartScreen warn me?

For now, yes. PitLaunch is not code-signed yet. Choose More info, then Run anyway. Release pages include a SHA256 table for verification.

What happens when PitLaunch updates?

Installed copies update themselves. Your setups live outside the installation folder, so updates do not replace them.

Do I need a physical Stream Deck?

No. Stream Deck Mobile turns your phone into the same two-button switch between Desk and Sim Racing.

How else can I trigger a setup?

Use the app, system tray, a per-setup hotkey, game automation, Stream Deck or Stream Deck Mobile.
